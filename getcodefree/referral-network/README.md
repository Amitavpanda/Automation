# GetCodeFree Referral Network — Founding Doc

**Model**: Owned-audience community. We are the connector — existing outreach pipeline feeds clients in, agency-fit work stays in GCF, overflow routes to our dev/agency list for a written finder's fee. Two simple earn routes: (a) keep agency/ABP work ourselves (real margin), (b) refer overflow for 5-20% fee.

**Why not a cold-start marketplace**: Supply side already seeded — we hold a dev/agency list. Demand side = existing outreach engine (agents scrape → we pitch). Community is a **routing layer on top of what we already do**, not a from-zero two-sided marketplace. Own group = owned audience, we hold standing + credibility, clients see "proof of network."

**Positioning**: NOT another job-alert group (saturated commodity — see research below). An **admin-curated project network** with verified both-sides + written commission terms. Community = delivery + credibility container, NOT the demand engine. Outreach generates clients; the group gives them a home + monetizes spillover.

## Why This Works (Research, Aug 2026)

| Precedent | Mechanics | What to Copy / Avoid |
|---|---|---|
| **Freelance Nexus India** (freelancenexus.in) | Free WhatsApp+Discord community. "Members share leads and refer each other; if someone can't take a project, it goes to the community first." Daily gig alerts; peer support; monetized via growth/courses/ads | Copy: referral-first culture, community-if-you-can't-take-it. Avoid: no formal commission = no revenue. We add the broker layer |
| **IT Referral Jobs** (itreferraljobs.in, @ITReferral_Jobs, 17.9K TG subs) | Daily referral/job posts (Amazon/MS/Infosys/TCS), ~12 posts/day, 23% engagement, WhatsApp channel + SEO blog + course upsells | Proves: high-freq curated posting + cross-channel distribution works. It is job-board, not project brokerage — that's our gap |
| **"Freelancing Group"** (WhatsApp, admin-mediated) | "Admin posts projects and freelancers pick up with admin guidance. Only admins can post." Serious members only, removed if disruptive | Copy: **admin-only posting** — kills spam, builds trust. This is the single most important mechanic |
| **Aviral AI** (live Freelancer posting) | AI agency hiring referral partners: "you make the intro, we close/build/manage, you earn commission as long as client stays." Recurring commission on retainers | Proves: agencies actively *pay* for referrals, recurring. GCF can run BOTH sides: (a) be the Aviral principal paying referrers, (b) be the referrer earning from overflow partners |

## Fit with Goal (GOAL.md)

Community = one platform feeding the agency + spillover monetizer. Same scoring rule drives routing:

- **Retainer-shaped / fits Offers 1-5** (SaaS owner, funded startup, ABP/DDD shop, enterprise modernization) → **keep for GCF**, pitch as studio
- **Overflow / small / non-ABP scope** → refer out to dev/agency list for finder's fee (5-20%)
- **Consistency via outreach cadence, not the group** — leads come from pitching existing pipeline. Group is the home + reputation machine that feeds inbound later

## Mechanism

- **Channel**: private Telegram group (scales past WhatsApp 1024 cap). Optional WhatsApp community as feeder later
- **Two roles**:
  - **Project posters** (clients / agency overflow / other brokers) — post requirements
  - **Member devs/agencies** — verified, take referred projects
- **Flow**:
  1. Inbound requirement lands (client DM, Xing/zx overflow, funding-agent, lead-agent, gig-agent feeds)
  2. Admin (Amitav) qualifies: scope, budget, timeline, owner intent
  3. Agency-fit → GCF keeps. Overflow → posted to group
  4. Member claims → admin introduces → member signs finder's-fee agreement → work + payment happen member↔client
  5. Finder's fee invoiced on client payment (paid only after client pays member)
- **Admin-only posting** (Freelancing Group mechanic). Members browse + DM to claim

## Rules (group pin)

1. Only admins post projects — members DM admin or a claim bot
2. No spam, no "buy my course", no scraper junk — removal on first offense
3. Members submit a verified profile to join: name, skills, live links (portfolio/platform history), contact
4. Finder's-fee agreement signed **before** intro (template below)
5. Fees paid only after client pays the member — zero risk to members
6. No poaching members' clients outside posted projects
7. Severe/jokes = removed. Muted channel: posts only, discussion in linked chat

## Commission Terms (finder's fee)

| Referral type | GCF cut | Notes |
|---|---|---|
| Pure referral (intro only, member closes) | 5-10% | Standard for passive intro |
| GCF helped spec/qualify/shortlist (client told member) | 10-15% | Covers qualification work |
| GCF ran sales + scoped, member delivers | 15-20% | Covers pre-sales labor |
| Investor/presented deal (GCF secures the direct client, member handles build) | 20-30% | Covers full sales cycle |
| **Recurring** client (retainer/multi-phase) | commission on each phase, or 5% of recurring for duration | Aviral precedent: recurring commission |

Hurdle: fee applies on project value ≥ ₹15,000 (or $200). Below hurdle = free referral (goodwill, rare).

## Agreement Template (before every intro)

```
GetCodeFree Referral Agreement — ref #____

1. GCF introduces [member] to [client] re: [project].
2. If [client] pays [member] for this project (any agreed scope), finder's fee = ____% of gross client payment, invoiced by GCF after client payment clears.
3. Covers 24 months from intro for any expanded/altered scope with same client.
4. Member warrants no sub-delegation without GCF consent.
5. Delay/redesign does not void fee; non-payment dispute = GCF mediator, member VS stops work until resolved.
6. Both parties agree confidentiality, no poaching.
Member: ___  Date: ___  GCF (Amitav Panda): ___  Date: ___
```

## Launch / Seed Plan

1. **Set up**: Telegram private group + pinned rules. Name: `GetCodeFree Referral Network — verified devs, curated projects`
2. **Seed devs (25-50 real)**: existing network + r/FreelanceIndia + r/forhire + freelance WhatsApp groups + Freelance Nexus Discord (2-3 devs each who want project flow). Each gets invite share
3. **Seed projects**: first 3-5 real overflow requirements from GCF's own pipeline (agency overflow like Inwizards/nopStation already queue). Group must show projects WEEK ONE — empty group = trust death
4. **Both-sides marketing**: post group link in r/FreelanceIndia, Freelance Nexus threads, existing WhatsApp communities (via DM, not spam)
5. **First 5 closed deals** = the proof the group sells itself on ("5 projects brokered, ₹X paid out")
6. **Grow**: after ~100 members + 5 deals, charge optional membership or take only referrals. Keep invite-only voice: scarcity builds trust

## Risks & Mitigation

- **Cold start (empty group)** — seed devs first, real projects week one (above)
- **Trust death (spam)** — admin-only posting + verified profiles + removal policy
- **Fee non-payment** — signed agreement + fee-on-client-payment + GCF as future-intro gatekeeper (member who dodges fee stops getting intros)
- **Poaching** — rule 6 + agreement clause 6
- **Time drain** — 30 min/day cap; pipeline feeds from existing agents, not new manual scraping. Treat as one more promotion channel, not a job
- **Legal/regulatory** — India: finder fees legal as brokerage commission; invoice GST-appropriately as fee for service. Keep written agreements
