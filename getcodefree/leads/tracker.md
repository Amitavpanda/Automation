# GetCodeFree Lead Tracker

## Lead Sources

- **LinkedIn**: Founders posting about building, hiring devs, fundraising
- **X/Twitter**: #buildinpublic, #mvp, indie hacker posts
- **Upwork**: Open projects matching stack
- **Wellfound**: Startups hiring founding engineers
- **Crunchbase**: Recently funded companies
- **Inbound**: hello@getcodefreetech.com, website form

## Scoring

| Signal | Score |
|---|---|
| Has funding | +10 |
| Needs MVP built | +8 |
| Technical founder (can evaluate) | +5 |
| Has budget range | +5 |
| Non-technical founder | +3 |
| Just posting ideas (no action) | -5 |

## Pipeline

1. **Discovery** — Found in scraping / inbound
2. **Qualified** — Fits ICP, budget alignment
3. **Contacted** — Outreach sent
4. **Call booked** — Strategy call scheduled
5. **Proposal** — Scope + quote sent
6. **Closed** — Project started
7. **Shipped** — Delivered
